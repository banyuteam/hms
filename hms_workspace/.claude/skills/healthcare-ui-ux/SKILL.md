# Healthcare UI/UX Engineering

## Use when
Designing patient, clinical, pharmacy, laboratory, radiology, billing or hospital operational interfaces.

## Principles
- Optimize for accurate, efficient and safe work, not visual novelty.
- Keep patient identity and encounter context unambiguous.
- Show provenance, timestamps, status and source when clinically relevant.
- Distinguish draft, signed, amended, verified and imported data.
- Prevent accidental patient/context switching.
- Use confirmation and review for consequential actions.
- Support keyboard, screen readers, clear focus and appropriate contrast.
- Avoid color-only status communication.
- Design dense data views with hierarchy and scanability.
- Never fabricate clinical values or imply AI output is clinician-approved.
